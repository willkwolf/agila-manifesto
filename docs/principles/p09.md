# Principle 9: In Complexity, Understanding Follows Action

> **Canon (Esperanto)**:  
> *9. En komplekseco la kompreno sekvas la agon.  
> Kie la dinamiko estas nelinia kaj la partoj adaptiĝas, longdaŭra antaŭdiro estas limigita, kaj malgrandaj sekuraj sondoj donas pli da informo ol plano. Antaŭ ol agi, ni diras, kio montrus, ke ni malpravas. Funkcianta programaro ĉe reala uzanto estas nia ĉefa pruvo, kaj la kompleksa sistemo, kiu funkcias, kutime kreskis el simpla, kiu funkciis; ŝanĝiĝantaj postuloj estas informo. Mezuro estas signalo, ne celo; kiam ĝi fariĝas celo, ni pridubas ĝin kaj defias ĝin per alia mezuro, kiu povas kontraŭdiri ĝin.  
> Bazo: limigita antaŭdirebleco en neliniaj dinamikaj sistemoj; hipotezo estas scienca nur se ĝi estas refutebla; mezuro estas perda bildigo de la realo, kaj optimumigi ĝin movas la sistemon al regionoj, kie la bildigo ne plu konservas tion, kio gravis.  
> Signalo: ĉiuj mezuroj estas verdaj kaj la uzantoj malkontentas.*

---

## English Translation
Where dynamics are nonlinear and components adapt, long-term prediction is limited, and small safe-to-fail probes provide more information than a plan. Before acting, we state what would show we are wrong. Working software in the hands of a real user is our primary proof, and a complex system that works invariably evolved from a simple system that worked; changing requirements are information. A metric is a signal, not a goal; when it becomes a goal, we question it and challenge it with another metric that can contradict it.

- **Basis**: Bounded predictability in nonlinear dynamic systems; a hypothesis is scientific only if it is falsifiable; a metric is a lossy projection of reality, and optimizing it drives the system into regions where the projection no longer preserves what mattered.
- **Signal**: All metrics are green yet users are dissatisfied.

---

## Theoretical Grounding: Complex Adaptive Systems and Epistemology

1. **Nonlinear Dynamics & Cynefin**: In complex systems (where agents co-adapt and causes are non-linear), cause-and-effect can only be perceived retrospectively. Extensive a priori planning fails because the system changes in response to the plan. Small, safe-to-fail probes generate actionable feedback that no theoretical model can provide.
2. **Karl Popper's Falsifiability**: An assertion is scientific and meaningful only if one specifies the empirical observation that would prove it false. Before deploying an architectural or product feature, teams must state their falsification criterion.
3. **Gall's Law**: *"A complex system that works is invariably found to have evolved from a simple system that worked. A complex system designed from scratch never works and cannot be patched up to make it work."*
4. **Goodhart's / Campbell's Law**: When a measure becomes a target, it ceases to be a good measure. Because any metric is a lossy projection of multi-dimensional reality, optimizing for a single metric incentivizes behavior that degrades unmeasured system health.

---

## Operational Diagnostic: The Signal in Practice

- **Observable Signal**: Engineering dashboards display 100% green metrics (high velocity, high code coverage, sprint goals met), yet end users report severe frustration, user churn accelerates, and product value declines.
- **Structural Remedy**:
  - Shift validation from synthetic internal metrics to working software running in production with real users.
  - Implement countervailing paired metrics (e.g., pair velocity with customer error rate; pair code output with defect escape rate).
  - Treat changing user requirements not as project management failure, but as valuable newly acquired information.
