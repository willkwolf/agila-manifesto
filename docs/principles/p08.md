# Principle 8: Every Agent is Part of the Communication Structure

> **Canon (Esperanto)**:  
> *8. Ĉiu agento estas parto de la komunika strukturo.  
> Homo aŭ maŝino, ĉiu agento, kiu produktas artefaktojn, formas la sistemon kaj estas formata de la strukturo, en kiu ĝi laboras. Agentoj de artefarita inteligenteco do havas limojn kaj posedanton, kaj ilia rezulto transiras teaman limon nur per homa decido.  
> Bazo: agento estas unuo de la grafo kun enigoj kaj eligoj; ĝiaj eligoj transiras limon nur per pakto, kiel tiuj de ĉiu alia unuo.  
> Signalo: kodo aŭ teksto, kiun neniu posedas kaj neniu povas klarigi.*

---

## English Translation
Human or machine, every agent producing artifacts shapes the system and is shaped by the structure in which it works. Artificial intelligence agents therefore have boundaries and an owner, and their output crosses a team boundary only by human decision.

- **Basis**: An agent is a graph unit with inputs and outputs; its outputs cross a boundary only through a pact, like those of any other unit.
- **Signal**: Code or text that no one owns and no one can explain.

---

## Theoretical Grounding: Socio-Technical Multi-Agent Graph Theory

In traditional organizational models, the vertices of the communication graph $V_C$ were assumed to be strictly biological humans. In modern engineering ecosystems:
$$V_C = V_{\text{human}} \cup V_{\text{agent}}$$

Where $V_{\text{agent}}$ includes autonomous coding agents, LLM assistants, automated refactoring pipelines, and synthetic code generators.

Because these agents generate software artifacts (code, documentation, configuration, tests) that alter the modular graph $G_M$, they participate directly in Conway's homomorphism. Uncontrolled proliferation of agent-generated code across boundaries introduces latent coupling, unverified assumptions, and unowned maintenance burdens.

To preserve system stability (Principle 3):
1. Every agent node must be bounded within an explicit decision unit.
2. Every agent must have an accountable human owner (`Human-owner: @username`).
3. Agent outputs can cross a team boundary only after explicit human evaluation and approval under a verified pact.

---

## Operational Diagnostic: The Signal in Practice

- **Observable Signal**: Large PRs consisting of hallucinated or synthetic code merged without comprehension; orphaned services or modules in production that no engineer can explain or modify safely.
- **Structural Remedy**:
  - Enforce strict agent boundaries: agents propose, humans approve.
  - Require that every agent-generated pull request declare a designated human sponsor.
  - Require automated test verification and human peer review before any agent output crosses a team interface.
